# 中文可视化电商图片制作界面

## 1. 本地启动（Windows / macOS / Linux）

需要 **Python 3.10+**，打开终端并进入仓库目录：

```bash
git clone https://github.com/hren44813-dotcom/huangren.git
cd huangren
python -m pip install -r requirements-ui.txt
python -m streamlit run app.py
```

终端会显示本机地址（通常是 `http://localhost:8501`），浏览器访问即可。**无需 GitHub 密钥即可在本机离线排版。**

Windows 可用：

```powershell
py -m pip install -r requirements-ui.txt
py -m streamlit run app.py
```

## 2. 操作流程

1. 选择目标平台：淘宝 / 天猫，或阿里国际站。平台选择不是自动认证或最新规格查询。
2. 上传单张或多张产品原图；建议透明 PNG。每张不超过 12MB，最多 25 张。
3. 选择制图类型，例如主图、白底搜推、SKU、3:4 竖图或详情模块。
4. 选择每种图的配色数量（1~4）。白底搜推图永远只输出 1 张；多配色不会虚构额外产品视角。
5. 如需要文字，填写真实标题、材质、孔距、规格等；没有数据可留空，不会自动编造。
6. 点击「开始批量生成图片」，检查预览与错误信息，下载 ZIP。压缩包内含 `report.json` 供质量检查。

**输出模板尺寸**：主图 / 白底搜推 / SKU 1440×1440；竖图 1440×1920；详情模块 800×1600。白底搜推图为 JPG，程序检查背景和 3MB 上限。这是当前项目制图规格，不代表任何电商平台的实时审核标准。

**不变形原则**：源图仅裁去透明画布边距并做等比例缩放。压缩导出可能带来细微像素差异。白底模式不自动抠图，不接受普通杂色背景照片。

## 3. 星河 AI（可选）

使用第二个「星河 AI 详情页」标签页，输入单张参考图、产品名称、你审核过的提示词、模型名、API Key，并主动勾选数据上传与费用同意后，点击调用。系统只在点击后调用仓库中的：

`.agents/skills/xinghe-crossborder-detail-3/scripts/generate_image.py`

脚本默认使用技能原有的第三方 `https://xinghe.xin/v1`，模型名默认示例为 `gpt-image-2`；具体可用模型、价格、实际像素等以服务商为准。本界面不自动读取外部账号余额或验证付费能力。**UI 不会写入你的 API Key 到磁盘或 GitHub**，密钥作为子进程环境变量传递；不要将此应用未经鉴权直接公开部署。

AI 生成可能改变产品孔位、钥匙、锁片结构，请与原参考图逐一人工对照。部分模型可能不严格遵守张数和分辨率，请以实际返回文件为准。接口超时不意味着一定没有费用。

## 4. 限制与安全

- 项目尚未集成自动抠图、批量产品精修、淘宝后台自动上架。
- 生成的配色版本仅展示不同背景/强调色，不保证每张文案、角度、构图完全不同。
- 原图与生成文件保留在运行界面内存及临时工作区，不自动上传 GitHub 或任何电商平台；AI 模式例外，会发送选中的参考图和提示词给第三方。
- **公开部署前**请增加登录认证、速率限制、费用控制、访问审计，禁止泄露客户保密资料和 API Key。
- 运营助理可离线使用标准功能，真实商业素材请自行确认商标、版权和产品数据准确性。
