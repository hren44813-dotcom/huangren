# SKU 模板 V3：三套工业风 + 原尺寸图

## 操作

1. 安装依赖后执行 `python -m streamlit run app.py`。
2. 在「③ Excel SKU / 工业模板 V3」选择：蓝白工业参数风、黄黑工业风、灰白极简技术风，或保留 V2 经典版式。
3. 下载对应 Excel 模板，在 `SKU清单` 中填写：`SKU编码`、`商品名称`、`图片文件名`；其余信息只有真实核实后才填写。V3 可选填写 `尺寸图文件名`。
4. 将产品原图和每个 SKU 对应的原尺寸图一起上传（ZIP 或多选），文件名必须完全匹配（大小写忽略）。
5. 生成、预览、下载 ZIP，包含逐行失败/成功报告、质量报告和 1440×1440 的 SKU JPG 图片。

## 设计与质量

- 所谓“模板复刻”在 V3 中指对既定工业风格预设**统一版式**，并非对任意用户上传成品图片进行像素级克隆，也不会识别图片里数字并重写。
- V3 仅缩放和贴入原照片，不重新画螺孔、尺寸线或标注数字；有损 JPEG 输出会产生轻微像素差异，因此仍要逐张人工核验。
- 未提供尺寸图时会输出仅包含产品照片和已填参数的版本，不伪造标注；填了尺寸图文件名而上传包中找不到时，该行失败。
- 预设风格决定标题/背景颜色，V3 不应用 Excel 中的 `色块颜色` / `标题字色` 自定义字段；需自定义请使用 V2 版式。
- 产品与尺寸图都要有合法来源；避免把客户保密图纸上传公开 GitHub。源图只在运行环境中处理。
