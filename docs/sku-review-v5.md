# V5 SKU 模板库、位置微调与发布前审核

## 1. 启动

```bash
pip install -r requirements-ui.txt
python -m streamlit run app.py
```

选择 `③ Excel SKU / 工业模板 V5` 选项卡，并选择 `V5 自定义布局与模板库（兼容V4）`。

## 2. 自定义排版（V5 增强）

- 上传参考模板，只用于预览旧图的标题、产品、尺寸图、参数位置。
- 选择四个区域之一，使用方向按钮按 5、10、20 或 40 px 微调。也可直接填写 X/Y/宽/高。
- 程序会拒绝区域重叠、越界和过小的区域，预览线框不会保留在导出图中。
- 如需在最终图中使用底图，必须上传不含旧商品、旧字、旧 Logo 的 **1440×1440** 净背景，并明确确认。系统不会智能清除旧内容。
- **这不是鼠标拖拽编辑器**，而是按钮微调、数值编辑和实时预览；不保证任意参考图可被自动像素级复刻。

## 3. 模板库

在「本机模板库」中输入名称并保存，之后可在下拉框选择并载入。支持删除已保存模板、覆盖同名模板，或下载 JSON 文件在其他电脑导入。

- 模板存储位置：`.local/sku_templates/`，不纳入 Git。
- 只保存位置和颜色，不保存图片和产品参数。
- 在线临时部署环境的数据可能丢失，因此推荐下载 JSON 备份。多用户共用同一服务器时，本机模板库不是私人账号隔离存储。

## 4. 人工审核

Excel 批量生成后，页面会显示逐张审核表。每张默认 **待审核**，且检查框均不勾选：

1. 产品孔位、结构、配件、比例与原图一致。
2. 原尺寸图、孔距、长度和数字标注真实。
3. 卖点、材质、参数、标识可追溯到已核实资料。
4. 文字在手机上清晰，平台尺寸、文件大小等实时要求已核对。

只有四项全部勾选，才允许将结果标为「通过」。如果有问题标「返工」并填写原因。没有人工通过的图片不会进入已通过 ZIP。审核下载包中包含 `review_report.json`、`review_report.csv`、`approved/` 目录（仅放人工通过的 JPG）。报告包含每张图片的 SHA256 用于校对。

**注意：** 程序并不会自动确认机械结构正确，也不连接电商平台上架系统。审核是人工确认并留痕，不能替代实际商品资料和平台审核。
