# 竞品 SKU 每日监测 · 运营助理操作指南

用途：淘宝/天猫及其他公开竞品链接的**人工观察数据**登记、历史存档和跨日期对比。与供应商采集数据库、V13 产品参数证据库完全分离；不自动抓取网页、不假设能读取所有 SKU 报价。

## 开始使用

1. 运行现有 Streamlit 程序：`streamlit run app.py`，在左侧选择「竞品监测」工作区，再进入「竞品 SKU 每日监测」。
2. 下载空白 CSV 模板，用 Excel 填写。**一个链接里有多个 SKU，每个 SKU 占一行**，每行写相同日期与商品链接。
3. 将当天看到的每个 SKU 报价写入「SKU价格」。链接销量、评价是否带图、优惠券、活动属于**链接级**信息，同一天同链接多 SKU 行必须一致。
4. 「未显示」不能填 0：销量留空；评价/优惠券/活动填「未显示」。截图文件名是相对名称，图片文件**不会自动保存进数据库**；请在自己的资料目录保留原始截图。
5. 上传 UTF-8 CSV，先「预检」再明确确认保存。所有导入行在一个 SQLite 事务中完成；不允许同日同链接同 SKU 的不同内容悄悄覆盖已有记录。
6. 选择日期查看本次 SKU 价格、**上一次实际记录日期**的价格和变化，再下载可供 Excel 打开的价格变化 CSV。某 SKU 今日没记录，仅显示「本次未记录」，**不能推断下架**。


## 第五批：固定竞品清单与每天待监测任务

在左侧「竞品监测」工作区内：

1. 下载「竞品链接与 SKU 固定清单模板」，维护`竞店、竞品链接、SKU、币种、监测状态`。**一个链接多个 SKU 就填多行**。监测状态仅为`启用`或`停用`，停用不会删除历史观察数据。
2. 上传清单后先「预检固定清单」，检查新增、更新、未变化的 SKU 数量，再主动勾选确认进行正式保存。每次修改保留追加式操作历史；未列在本次 CSV 中的其他旧 SKU **不会被自动删除或停用**。
3. 选择任务日期（注意页面默认是**本机服务器日期**，不一定等于淘宝运营所处的北京时间），下载「当天 SKU 监测任务表」。该表自动填好日期、链接、SKU、币种，但当天 SKU 价格、销量、优惠券、活动、评价信息全部**留空**，必须以当天实际观察结果填写。填好后继续使用原有「预检数据」→「确认保存历史数据」流程。
4. 主管查看「应监测 SKU / 已完成价格记录 / 未完成待补价格」及完成率。当前进度只按**固定清单内启用的 SKU**计算；当天没有记录的是「待监测」，有记录但价格空缺的是「已记录待补价格」，不会误判为下架或涨跌。
5. 有观察证据时显示价格异常变动、优惠券变化及活动变化提醒。价格变动阈值默认 **20%**，可由运营选择 5%～100%。价格变化比较的是同链接同 SKU **上一次记录日期**，并非默认昨天；币种不同、历史价格 0 或价格未知时不计算百分比。优惠券与活动只在前后都明确观察到`有/无`时才标记变化，`未显示`不会被当作`无`。
6. 本系统目前只提供**页面内查看**，没有后台定时检查、消息推送、淘宝授权抓取或自动任务分配。运营助理仍需每日进入页面填报；真实截图图片不会自动写入数据库。

固定清单与监测观察保存在同一个本机 SQLite `.local/competitor_monitor.sqlite3`。原有观察表保留追加式不可变约束；固定清单表允许明确操作的状态调整，另有不可修改的事件记录，避免静默更改历史。生产使用前请备份数据库。

## 模板字段

| 字段 | 示例与含义 |
|---|---|
| 日期 | 2026-10-28 |
| 竞店 | 竞品 A 店 |
| 竞品链接 | 公开 HTTPS 商品页面 URL，同一链接维持一致写法 |
| SKU | MS705-304不锈钢（每个可选规格单独记录） |
| SKU价格 | 12.50；不确定价格时留空，不填区间 |
| 币种 | CNY 或 USD（ISO 三字母） |
| 链接销量 | 商品链接显示的累计销量，未显示留空 |
| 评价带图、优惠券、活动 | 只填「有」「无」「未显示」 |
| 截图文件名 | 20261028_MS705.png（可选） |
| 备注 | 价格优惠条件、时间、观察说明（可选） |

## 设计与数据安全

- SQLite 在仓库的本地 `.local/competitor_monitor.sqlite3`，首次**正式**导入才新建；只读查询和预检不会新建。
- 保存后数据只追加，数据库触发器禁止修改或删除采集事实。
- Excel 导出会防止公式注入；CSV 文件限制为 UTF-8、2 MB、5000 行，并拒绝危险 URL、文件路径和重复行。
- 报表的涨跌是同一链接同一 SKU 的**最近两条有效日期观察**对比；货币不同、未显示价格、首次记录均不会强算涨跌。
- 后续若要更正误填数据，应建立有审计记录的更正流程，不要直接在 SQLite 中 UPDATE/DELETE。
- 不会访问淘宝后台、绕过验证码、采集非公开经营数据，也不保证人工截图里的金额持续有效。
