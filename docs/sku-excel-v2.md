# Excel 批量 SKU 制图 V2.0

## 适用场景

工业拉手、锁具、阻尼转轴、铰链等产品有几十个 SKU，需要运营助理逐一标注型号、孔距、总长、材质等。**只使用用户实际核实的参数**，不自动计算孔距或修改结构，原产品照片仅等比排版。

## 一、下载模板

打开中文页面「③ Excel 批量 SKU（V2.0）」点击「下载 Excel SKU 填写模板」。仓库内模板位于：`assets/templates/sku_import_template.xlsx`。

- 只填写 `SKU清单` 工作表，第一行表头不可修改。
- 必填列为：`SKU编码`、`商品名称`、`图片文件名`（例如 `MS705-01.png`）。
- 其余列：`型号`、`孔距(mm)`、`总长(mm)`、`材质`、`表面处理`、`色块颜色`、`标题字色`。
- 孔距/总长只填写真实尺寸数值，不要加 `mm` 后缀；生成时程序加 `mm`。**对已含单位或特殊尺寸的文本，请先整理成不带单位的真实数据。**
- SKU 编码按文本格式填写，避免 Excel 将 `001` 自动改为 `1`。公式单元格不允许导入（请粘贴为值）。
- `演示示例` 工作表只为教学，不参与导入，不要将演示值当真实参数。

## 二、上传产品照片

将原始素材用 Excel 中的 **完整文件名（含扩展名）** 命名，建议透明 PNG；JPG、JPEG、WEBP 也支持。可以一次上传图片 ZIP（≤70MB）或多选图片。图片本身每张≤12MB。

上传后每个 SKU 精确匹配对应文件（文件名不区分大小写），不会使用其他 SKU 的图替代。ZIP 中路径不会解压到服务器文件系统，重名文件直接拒绝。

## 三、生成并下载

点击「按 Excel 批量制作 SKU 图」。一次最多 80 行 SKU；每个 SKU 输出 1 张 `1440×1440` JPG，约束保持真实结构、原图不覆盖。会显示每一行成功或失败原因。

ZIP 中包含：

- `SKU_行号_编号.jpg`：每一行独立产品图
- `sku_import_report.csv`：逐行成功/失败报告（带 UTF-8 BOM，Excel 可正常打开）
- `sku_import_report.json`：逐行状态与原因
- `quality_report.json`：每张机器可测的尺寸/格式等检查 + 人工待验收项
- `report.json`：成功元数据/失败原因

机器质检无法保证真实产品结构、标注数据与平台最新准入规定。**上架前必须逐张核对产品形状、孔位、材质、数字、版式。**

## 四、命令行自动生成

```bash
python scripts/build_sku_excel.py --excel "assets/templates/my_sku.xlsx" --images "assets/input/photos.zip" --out "output/sku_images.zip"
```

输出 ZIP 含图片和报告；若有失败行，命令会返回状态码 2 方便自动化监控。

## 五、安全与限制

- 所有文件只在本地服务器实例内存和临时工作目录处理，**不调用付费生图 API**、不提交用户素材到 GitHub。
- 80 SKU / 120 图片 / 单图12MB / XLSX6MB / ZIP70MB；限制用来保护系统资源。
- 只接受 `.xlsx`，不支持旧版 `.xls` 或公式计算；表格中的数字可能丢失前导零，务必提前将相关列设为文本。
- 一个模板当前提供四行规格区域：型号、孔距、总长、材质/工艺，按非空字段展示；不会自创检测认证或耐用度。
- `色块颜色` 可填写例如 `#0D7FF4`、`#F5C518`；黄色 `#F5C518` 自动使用黑标题字，其他颜色默认白字。
