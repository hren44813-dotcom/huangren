# 电商图发布前质检及自动化测试

## 自动质检

使用中文 Streamlit 界面批量生成图片后，下载的 ZIP 包包含：

- 实际导出的 JPG 图片文件；
- `report.json`：文件尺寸、模式、大小与错误信息；
- `quality_report.json`：逐张机器检查结果，以及**尚未完成**的人工验收条目。

自动检查项目：文件可读、扩展名与实际格式匹配、模板像素尺寸；白底搜推图额外抽查画布边缘是否为白色，并检查 JPG 文件大小小于 3MB。这些检查**不等同于**确认产品真实结构、材质、参数、平台最新审核规格。白边抽查无法证明原图已经完整抠图。

## 人工必查项目

- 与供应商或实物照片逐项比对：产品本体、孔位、零部件、金属质感、比例是否一致；
- 确认主图出现的型号、材料、开孔尺寸、扭矩、测试数据有可追溯依据；
- 确保文字在手机端清晰、不遮挡产品；
- 登录对应平台，核对**当前**尺寸、文件格式、宣传规范要求。项目中的尺寸是内部预设，不是平台官方实时保证。

未经人工检查，不要把 `auto_pass: true` 视为可直接上架。

## 防止旧图误用

“批量制作”页面会根据上传文件内容、Logo、平台、规格、颜色和其他表单内容生成输入指纹。只要任何一项变化，之前的导出结果就会被隐藏，需重新点击生成，以免把旧产品文件下载为新 SKU。

## GitHub 持续集成

仓库中 `.github/workflows/ci.yml` 定义了 GitHub Actions，针对推送至 `main` 和 Pull Request，在 Python 3.10 和 3.12 环境运行语法检查和离线单元测试。

它**不会调用付费 AI 接口**，不需要 API Key；GitHub 上通过测试也不代表 Streamlit 界面已完成浏览器人工验收。

本地执行：

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

若要实际使用网页，再安装 `requirements-ui.txt` 并执行 `python -m streamlit run app.py`。
