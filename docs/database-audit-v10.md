# 数据库 V10 审查报告

## 已修复
1. 未版本化 SQLite 文件可能被误接管：只允许空库初始化。
2. schema 检查新增必需表/列、主键、外键与审核保护触发器定义检查。
3. 审核摘要必须保留四项检查，并校验统计、状态、图片摘要与任务阶段。
4. 旧审核缺少核验依据：保留历史但撤销发布就绪标记，要求重新审核。
5. 健康检查改为只读连接。
6. 审核历史增加 UPDATE/DELETE 触发器，并检测触发器缺失或被削弱。
7. 逐项比较任务表与 JSON 主记录的字段。
8. 增加模板名称键、摘要、导入标记校验。
9. 文件名大小写冲突按 casefold 去重。
10. V1 备份只在临时快照中升级。

## 验证范围
数据库专项与 CLI 测试覆盖初始化、只读检查、V1 迁移、旧审核降级、触发器、字段不一致、模板摘要、备份/恢复和旧 JSON 预演。GitHub Actions 需继续在 Python 3.10/3.12 环境运行。

## 尚未验证
- 未访问用户电脑的真实 .local 数据库，未迁移真实私有历史。
- 离线测试不能代替真实浏览器、商品图和目标环境恢复演练。
- 触发器和 SHA256 不是企业级防篡改审计；多人协作需要服务端数据库、身份认证、权限及备份保留。
