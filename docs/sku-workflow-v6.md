# V6 SKU 运营四步工作流（兼容 V2–V5）

## 目标

减少多 SKU 工业五金制图中常见的“产品图用错、孔距套错、旧审核结果被重复使用、返工原因丢失”的风险。面向运营助理和复核人员，**不自动替代人的实物检验**。

## 开始使用

```bash
python -m pip install -r requirements-ui.txt
python -m streamlit run app.py
```

打开「③ Excel SKU / V6 制图审核流程」，依次执行四步：

### ① 商品资料预检查

- 选择 V2、V3 预设主题或 V5 自定义模板；上传 SKU Excel 与产品图片 ZIP/多张图片。
- 点击「预检查 SKU 清单和图片匹配」：检查编码是否重复、图片名称是否精确匹配、损坏/过小图片、孔距总长格式、需要时核对尺寸图文件名。
- 检查失败的行会显示原因；有错误时建议返回修复后重检。若需紧急处理，可明确勾选“仍仅对可生成的行制图”；不会拿别的图片替换缺图。
- **预检查并不核实尺寸标注或材质是否真的符合实物。** 资料变化会使本轮预检查失效。

### ② 批量制作（内部未审核）

只有当前输入预检查通过，且至少存在 1 条可生成 SKU，生成按钮才会启用。生成时保留相应 SKU 的来源资料及单独失败报告。

输出「内部制图包」用于检查/返工，**不是上架成品**。更换 Excel、产品图、背景、版式或平台后，以前的生成结果不会作为当前输入的结果展示。

### ③ 人工审核

每张图片默认待审核，审核人员逐项核对：

- 产品孔位/结构/配件/比例；
- 孔距、长度和尺寸图标注真实；
- 材质、工艺、性能和卖点有资料支持；
- 字体可读、无遮挡，符合目标平台当前要求。

四项确认后才能标记“通过”；有缺陷标记“返工”并写具体问题。未确认的图片不能进 `approved/`。

### ④ 审核确认、导出与追溯

- 填审核人标识，点击「确认并保存当前审核记录」；之后下载审核 ZIP，内有 `review_report.json`、`review_report.csv` 和人工通过的 `approved/` 图片。
- 修改审核表会使刚才的下载状态失效，必须重新提交；更换文件内容或失败数量时，原审核报告无法用于本次图片。
- 流水摘要记录在 `.local/production_runs/<随机批次ID>.json`，可在页面的“本机任务流水记录”查看当前机器近 20 个任务。记录不包含原始图片、实际数值表或密钥。
- 这不是多人协作服务：同一台服务机的数据属于该机器，建议为不同人员部署独立实例。本机记录未做账号权限管理和加密，不能存放机密数据。在线临时主机数据可能随重启丢失。

## 安全边界与限制

- 本地生成工具不会上传商品图到第三方，也不会自动上架到淘宝、天猫或其他平台。单独的星河 AI 功能需要明确同意并连接第三方接口。
- SHA256 用来检测图片是否被换掉，不是独立的数字签名、审计认证或防篡改系统；有系统文件访问权限的人仍可能修改本地 JSON。
- 图片排版只做等比例处理，输入规格不会由算法推算、修复或伪造。原尺寸图应来自真实已核实资料。
- 审核通过只表示有人在此工作台确认过检查项，不能保证商品合规或平台会接受。
- 已下载到用户电脑的 ZIP 不能远程撤销；若发现错误，须停止上架、返工并重新留档。
