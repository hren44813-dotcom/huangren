# V4 自定义 SKU 模板布局指南

## 适用场景

工业拉手、铰链、机柜锁、阻尼转轴等批量 SKU，统一标题、产品、尺寸原图及参数区的位置。保留 V2 经典版和 V3 三套色彩模板。

## 使用方法

1. 启动：`python -m streamlit run app.py`。
2. 第③页选「V4 自定义参考模板布局」，选择蓝白、黄黑、灰白配色。
3. **参考模板图仅作定位辅助**：上传旧 SKU 图，对照预览图手动设置四个方框（X、Y、宽、高）。系统不会自动识别区域或移除旧图层。
4. 如要保留旧背景纹理，先制作**无产品、无文字、无参数的干净模板**，上传 1440×1440 净背景并确认。未确认时系统使用预设背景。
5. 保存 JSON 布局，下次可通过 JSON 导入。调整完区域后，上传 Excel 和产品/尺寸 PNG，批量生成。
6. 下载 ZIP 和逐行检查报告，人工检查图片结构、标注和字体清晰度。

## 对齐限制

- 四个方框不得重叠、越界，均需距离外边缘至少20像素，底图不会拉伸。
- 产品和尺寸图仅按原始比例缩放，允许裁切外围**透明空白**，不裁切主体，不重新绘制孔位和标注。
- “上传旧模板图”不是自动图层分离或像素级复刻：无法自动删除原本已印在背景上的产品和文字。真正需要原样复制时，请提供分层源文件或自行先处理干净的空白模板。
- Excel 缺失的字段不会被程序编造。字体可能因系统字库不同造成排版差异；导出的 JPEG 会产生轻微压缩差异。
- 不自动上传平台。发布前必须核对平台实时尺寸要求。

## 布局 JSON 格式

默认 JSON 仅包括 `version`、`canvas`、`style`、`colors`、`slots`；每个 `slots` 元素按 `[x, y, width, height]`，像素坐标在 1440×1440 中。导入最大32KB；恶意字段和不合法区域将被拒绝。下载样例可在 V4 页面操作。

## 命令行自动批量导出

先从网页界面保存 `sku_layout_v4.json`，然后运行：

```bash
python scripts/build_sku_excel.py --excel SKU.xlsx --images products.zip --layout sku_layout_v4.json --out output/sku_v4.zip
```

使用净背景时可附加 `--clean-background empty_1440.png`（必须已人工去除旧商品/旧标注）。
