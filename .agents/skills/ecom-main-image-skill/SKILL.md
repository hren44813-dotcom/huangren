# 电商主图 Skill

## 用户原始提示词

使用电商主图Skill。保持产品一致性。先识别商品信息和买家顾虑，再给出3个主图方向。每个方向只讲1个点击理由。选定方向后生成主图，并检查产品是否变形、卖点是否清楚、尺寸是否适合平台。资料里没有的功效和数据不要编。

## 执行顺序

1. 收集真实商品名、类别、参考照片、已有参数、使用场景以及买家顾虑；标明哪些资料缺失或不确定。
2. 输出3个主图方向：每个仅一个点击理由、一个视觉重点，不多塞功效和数字。
3. 等用户选择 A / B / C 才生成主图；保持锁体、孔位、铰链、拉手、转轴、钥匙、零件数量及尺寸比例不变。
4. 出图后复核产品是否变形、标题卖点是否清楚、实际像素与平台是否匹配、是否添加了未证实的材质/认证/盐雾/扭矩/寿命。
5. 不具备真实事实依据时留空或提示补充，禁止虚构性能、价格、销量、功能和认证。

本仓库前端第1个标签「主图方向策划」使用本地确定性规则；不是自动识图 AI。正式离线主图是 Pillow 基础排版，复杂创意需另外设计，且仍需人工复核。
